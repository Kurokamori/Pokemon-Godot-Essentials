# Pokemon Godot Essentials
This is Pokemon Godot Essentials, a semi-faithful port of the RPG Maker XP 'Pokemon Essentials' to Godot with ground-up reworking of all functionality to be as Godot-native as possible, while keeping a lot of the original tags, notations, and implementations.

This was created by Kurokamori as a tool for my own development and is generally a personal project, but you are welcome to use it and contribute to it if you'd like.
